# <span class="kind-class">GiantToadPixelOverlay</span> class

</div>

<div>

Places a Flutter overlay in the same letterboxed physical rectangle as the Giant Toad logical pixel canvas.

Use this as a direct child of a `Stack` above a `GameWidget`. Its child is laid out in logical pixels, then scaled using the viewport's pixel scale.
