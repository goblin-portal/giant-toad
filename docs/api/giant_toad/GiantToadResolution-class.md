# <span class="kind-class">GiantToadResolution</span> class

</div>

<div>

The baseline logical dimensions for a [GiantToadGame](../giant_toad/GiantToadGame-class.md).

Giant Toad preserves [width](../giant_toad/GiantToadResolution/width.md) by default and expands the visible logical height to match the available display. Use a fixed viewport explicitly when a game requires a locked aspect ratio.
