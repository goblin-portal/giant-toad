# <span class="kind-class">GiantToadNativeTextOverlay</span> class

</div>

<div>

Positions text on the game grid but rasterizes glyphs at display resolution.

Unlike [GiantToadPixelOverlay](../src_ui_giant_toad_overlay/GiantToadPixelOverlay-class.md), this does not transform a low-resolution text subtree. Font sizes and coordinates are converted before Flutter lays out and rasterizes each glyph, keeping scalable fonts sharp.

</div>
